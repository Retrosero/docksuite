# Skill — Doğal Dil İsteğini Sayfa Spec'ine Çevirme

## Amaç
Kullanıcının sayfa ile ilgili doğal dil isteğini teknik sayfa planına çevirmek.

## Adımlar
1. istek hangi modüle ait?
2. ERPNext karşılığı hangi DocType?
3. veri modeli değişikliği var mı?
4. sadece UI yerleşimi mi?
5. custom field / new doctype ihtiyacı var mı?
6. sonra sayfa spec'ini oluştur
