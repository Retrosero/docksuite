# Global Skill — Refactor to Components

## Amaç
Büyük ve karışık ekranları component mantığına geçirmek.

## Adımlar
1. Ekrandaki tekrar eden blokları bul
2. Ayrıştırılacak UI parçalarını listele
3. State'i page mi feature mı yönetecek karar ver
4. Ortak component'leri shared alana taşı
5. Event ve callback akışını sadeleştir
6. Sonuçta klasör yapısını netleştir
