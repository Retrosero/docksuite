# Global Skill — Form Architecture

## Amaç
Formları yönetilebilir ve tekrar kullanılabilir kurmak.

## Adımlar
1. Form alanlarını gruplandır
2. Zorunlu alanları ayır
3. Lookup alanlarını belirle
4. Validation kurallarını tanımla
5. Form state ile submit logic'i ayır
6. Başarılı / hatalı / loading durumlarını net tasarla

## Kural
İlk sürümde minimum alanlarla çalışan form çıkar.
Sonra gelişmiş alanlar eklenir.

## SaaS ek kontrolü
- Form içinde tenant'a özel iş kuralı sabit yazma
- Tenant ayarları gerekiyorsa config ile besle
