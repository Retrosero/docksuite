# Shipyard Skill — Task Module

## Amaç
Tersane için görev modülü tasarlamak.

## Temel alanlar
- görev adı
- proje / gemi
- blok / bölüm
- atanan ekip
- atanan kişi
- öncelik
- durum
- başlangıç tarihi
- bitiş tarihi

## Gerekli parçalar
- Task DocType veya uygun çekirdek eşleme
- taskService
- görev listesi ekranı
- görev detay ekranı
- durum güncelleme bileşeni

## SaaS ek kontrolü
- Görev yapısı tüm tersane firmalarında kullanılabilir olmalı
- Firma özel sabit alanlar temel modele gömülmemeli
