# Shipyard Skill — Technical Document View

## Amaç
Teknik dokümanları görev veya bölüm bazlı göstermek.

## Temel ihtiyaçlar
- görevle ilişki
- son revizyon bilgisi
- görüntüleme
- dosya türü gösterimi
- rol bazlı görünürlük

## UI parçaları
- doküman listesi
- doküman detay kartı
- revizyon etiketi
- aç/görüntüle aksiyonu
