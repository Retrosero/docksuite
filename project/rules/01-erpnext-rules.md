# ERPNext Rules

1. Var olan DocType'a yeni özellik gerekiyorsa önce Custom Field düşün.
2. Tekrarlayan işlem geçmişi gerekiyorsa yeni DocType düşün.
3. Standard REST API mümkünse özel endpoint yerine önce tercih edilir.
4. Customize Form ile yapılan kalıcı özelleştirmeler app içine alınacak şekilde planlanır.
