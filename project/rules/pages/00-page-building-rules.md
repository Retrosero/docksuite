# Page Building Rules

1. Önce standart DocType ve alanları araştır.
2. Sayfa geliştirmeden önce bu sayfa veri modeli değiştiriyor mu yoksa sadece UI mı karar ver.
3. ERPNext çekirdeğini yeniden yazma.
4. Önce resource API ile çöz.
5. UI ve veri modelini karıştırma.
6. Her sayfa mobil uyumlu ve Türkçe olmalı.
