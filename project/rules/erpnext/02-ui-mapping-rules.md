# ERPNext Rules — UI Mapping

1. Doğal dil isteğini önce veri modeli mi yoksa UI isteği mi diye ayır.
2. Sadece alanın ekrandaki yeri değişiyorsa veri modeli değiştirme.
3. Yeni veri gerekiyorsa önce standart alan var mı bak.
4. Alan yoksa Custom Field / New DocType kararını ver.
5. UI düzenini veri modeliyle karıştırma.
