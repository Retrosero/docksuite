# Hooks, Fixtures, Custom App

## Custom App
Projeye ait tüm özel geliştirmeler burada tutulur.

## Hooks
Frappe'ın çekirdeğine güvenli entegrasyon noktaları sağlar.

## Fixtures
GUI ile oluşturulan bazı özelleştirmeleri uygulama içine taşıyarak
yeni site kurulumlarında tekrar uygulanmasını sağlar.

## Ana kural
ERPNext core'a dokunma.
Özelleştirme:
- custom app
- hooks
- fixtures
üzerinden yürüsün.
