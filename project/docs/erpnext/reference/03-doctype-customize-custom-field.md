# DocType, Customize Form, Custom Field

## DocType
Yeni kayıt türü gerektiğinde oluşturulur.

### Ne zaman New DocType?
- tekrar eden işlem/geçmiş kaydı varsa
- ayrı form/list gerekiyorsa
- ayrı akış/izin gerekiyorsa

## Custom Field
Mevcut DocType içine yeni alan eklemek için kullanılır.

### Ne zaman Custom Field?
- var olan kaydın ek özelliği ise
- yeni kayıt türü açmaya gerek yoksa
- tekil nitelik tutuluyorsa

## Customize Form
Standart DocType üzerinde:
- alan ekleme
- field özelliği değiştirme
- görünürlük / zorunluluk / sıralama ayarları
için kullanılır.
