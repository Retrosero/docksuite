# Install / Migrate / Backup Flow

## Install mantığı
- app bench'e eklenir
- siteye install edilir

## Migrate mantığı
Migrate sırasında:
- patch'ler
- schema senkronizasyonu
- fixtures senkronizasyonu
çalışabilir.

## Backup mantığı
Site bazlı:
- database
- public files
- private files
- site config
yedeklenir.
