# Karar Rehberi - Flowbite Component Secimi

## Amac
Tasarim sirasinda Flowbite MIT component'leri ile custom UI arasinda tutarli karar vermek.

## Secim sirasi
1. Flowbite MIT component var mi?
2. Dogrudan kullanilabiliyor mu?
3. Proje standardi icin ince wrapper gerekiyor mu?
4. Tekrar eden bir pattern ise shared component yapilmali mi?
5. Hiçbiri yetmiyorsa custom component yazilmali mi?

## Karar kurallari
- Uygun Flowbite MIT component varsa once o tercih edilir.
- Flowbite Pro veya lisans disi varliklar kullanilmaz.
- Domain mantigi Flowbite markup'ina gomulmez.
- Tenant farkliliklari component icinde sabitlenmez.
- Mobil-first ve Turkce arayuz kosullari korunur.

## Kullanim alanlari
- sade saha ekranlari
- görev listeleri
- durum kartlari
- form aksiyonlari
- tablo ve filtre alanlari

## Cikti
- secilen Flowbite component
- wrapper gereksinimi
- custom yazilan kisim
- tenant / theme notu
