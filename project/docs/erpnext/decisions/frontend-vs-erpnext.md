# Decision: Frontend vs ERPNext

## ERPNext icinde kalsin
- admin
- ayarlar
- master data
- finans / stok / satin alma cekirdegi

## Ozel frontend olsun
- sade saha ekranlari
- hizli islem ekranlari
- mobil gorev akislari
- Flowbite MIT alanlariyla calisan MCP UI starter denemeleri

## Flowbite karar notu
- Ozel frontend gereken ekranlarda once Flowbite MIT component uyumu kontrol edilir.
- Uygun component varsa yeni tasarim yazmak yerine mevcut component kullanilir veya ince wrapper yazilir.
- Detayli secim kurali icin `project/docs/erpnext/decisions/04-flowbite-component-selection.md` referans alin.
