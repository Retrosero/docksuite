# Definition of Done

Bir feature veya DocType tamamlandı sayılmadan önce aşağıdakiler sağlanmalıdır:

## Teknik
- doğru yerde geliştirilmiş olmalı
- ERPNext core bozulmamış olmalı
- tenant-safe olmalı
- naming standardına uymalı
- fixture/app mantığı doğru olmalı

## Dokümantasyon
- ilgili specs güncellenmiş olmalı
- memory güncellenmiş olmalı

## Doğrulama
- migrate / sync uygulanmış olmalı
- ilgili yapı aktif sitede doğrulanmış olmalı
- temel smoke test yapılmış olmalı

## Git
- doğru feature branch kullanılmış olmalı
- anlamlı commit atılmış olmalı
- develop'e merge edilmiş olmalı
- main'e dokunulmamış olmalı
